# P-1: Basic Cisco Router Commands

## Overview
This practical demonstrates basic Cisco IOS configuration and verification commands using Cisco Packet Tracer.

## Objective
To practice basic Cisco router configuration commands, interface configuration, password configuration, configuration verification, and saving the router configuration.

## Device Used

- Cisco 2911 Router
- Cisco Packet Tracer

## Configuration Tasks

The following tasks were performed in this practical:

1. Enter privileged EXEC mode.
2. Enter global configuration mode.
3. Configure the console line.
4. Configure the router hostname.
5. Configure console password and login.
6. Configure enable password.
7. Configure enable secret.
8. Configure GigabitEthernet 0/0.
9. Assign an IP address to the interface.
10. Enable the interface.
11. Verify the interface configuration.
12. Check the router version.
13. View the running configuration.
14. View the startup configuration.
15. Save the running configuration to the startup configuration.
