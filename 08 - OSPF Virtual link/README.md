# P-8: OSPF Transit Area and Virtual Link

## Overview

This practical demonstrates OSPF multi-area routing using different OSPF areas.

The topology contains four routers connected through multiple OSPF areas:

- Area 2
- Area 1
- Area 0 (Backbone Area)

Area 1 acts as a transit area between Area 2 and Area 0.

This practical also demonstrates the use of an **OSPF Virtual Link** to logically connect an OSPF area to the backbone area when a direct physical connection is not available.

---

## Objective

The objective of this practical is to understand:

- OSPF multi-area configuration
- OSPF Router ID configuration
- Backbone Area 0
- Non-backbone areas
- Area Border Router (ABR)
- Transit Area
- OSPF Virtual Link
- Communication between different OSPF areas
